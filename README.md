# ДПО-1 — единый каталог курса

- Каталог для слушателей: https://smit1980.github.io/DPO-1_course/
- Страница преподавателя: https://smit1980.github.io/DPO-1_konspekt/
- Репозиторий страницы преподавателя: https://github.com/Smit1980/DPO-1_konspekt

Каталог содержит утверждённые ссылки на уроки 1–7. Урок 8 добавляется после загрузки финального комплекта.

## Как дополнить каталог

1. Добавьте публичный адрес урока, раздатки или промпта в `index.html`.
2. Для материалов в MAX указывайте только прямую ссылку на канал/страницу, без ссылки на репозиторий.
3. Перед публикацией проверьте доступ без авторизации, мобильный вид и отсутствие персональных, внутренних или конфиденциальных данных.
4. Репозитории публичны для чтения. Для прямого редактирования владелец добавляет GitHub-логин коллеги в Collaborators.
