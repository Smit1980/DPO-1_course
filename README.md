## Добавление материалов коллегами

Сайт статический, без сборки. GitHub Pages: ветка `main`, папка `/`.

1. Опубликуйте урок в учебном репозитории и проверьте адрес без авторизации.
2. В `index.html` скопируйте `<article class="card">`, измените название, описание и адрес. Сохраните исходную нумерацию урока.
3. При изменении количества карточек обновите число в шапке и начальный счётчик поиска. После ввода поиск считает карточки автоматически.
4. Добавьте конспект в `Smit1980/DPO-1_konspekt`: HTML в `web/`, DOCX/MD в `Docs/`, карточку в `index.html`. Можно дать ссылку на конспект в другом репозитории без дублирования.
5. Проверьте мобильный вид, поиск, ссылки и раздатку. Используйте отдельную ветку и pull request.

Публичность позволяет читать и скачивать файлы, но не даёт права записи. Без приглашения используйте fork и pull request. Для прямой записи владелец добавляет GitHub-логин коллеги в Collaborators.

Не публикуйте анкеты с персональными данными, договоры, реальные внутренние документы, пароли и ключи. Обезличивание не означает разрешения публикации. Преподавательские ключи и промпты изображений не добавляйте на общую страницу слушателей.

Все репозитории и страницы: [LINKS.md](LINKS.md).

Лекции Елены включены ссылками без изменения её файлов и прав доступа. Каталог содержит опубликованные страницы, а не заявление о завершении всей программы. Рабочая версия урока 8 находится вне основного маршрута. Отдельные конспекты двух лекций Елены и мультимодальной пары пока не предоставлены.
